
# Police for nvim icones :

Install first them go preference and change police.

```bash 
mkdir -p ~/.local/share/fonts/NerdFonts
cd /tmp
curl -fLO https://github.com/ryanoasis/nerd-fonts/releases/latest/download/CascadiaCode.zip
unzip -oq CascadiaCode.zip -d ~/.local/share/fonts/NerdFonts
fc-cache -f
```
